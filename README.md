# bela-sampler

Early-stage Bela Gem sampler. Loads WAV files from `samplesfolder/` and plays them in loop.

## Deploy (Bela)

```bash
./scripts/deploy.sh
```

Requires SSH access to the board (`root@bela.local` by default).

In order to connect to Bela you can type :

```bash
ssh root@bela.local
```
